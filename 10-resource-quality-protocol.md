# Resource Quality & Verification Protocol

## Verification states

### Pending
Imported or submitted but not yet checked.

### Verified
Key public information has been checked against an authoritative source or directly confirmed with the organization.

### Needs Update
Information appears outdated, conflicting, or incomplete.

### Community Partner
The organization has an active relationship with Feel at Home Connect. Partner status is separate from service verification.

## Required fields before Verified
- organization name
- service category
- public phone or contact method
- service area
- current public website or authoritative source when available
- basic description
- eligibility or intake requirements when available
- hours/intake information when available
- verification date
- verification method

## Verification methods
- official organization website
- direct organization confirmation
- government agency source
- established statewide/national service directory
- documented partner confirmation

## Freshness
Recommended review cadence:
- emergency/safety resources: frequent review
- high-demand housing resources: frequent review
- general resources: periodic review
- any user-reported problem: priority recheck

## User-facing language
Use:
“Information verified on [date]. Availability can change. Contact the organization to confirm current services.”

Do not say:
“Guaranteed available”
“Guaranteed admission”
“Guaranteed shelter”

## Report workflow
1. User reports an issue
2. Resource changes to review queue
3. Admin validates report
4. Record is corrected or marked Needs Update
5. Verification log records the action
6. User report is closed with outcome

## Safety rule
Do not publish confidential shelter addresses or operational details that could increase risk to survivors.
